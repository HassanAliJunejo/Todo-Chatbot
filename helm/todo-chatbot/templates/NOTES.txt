=============================================================================
ACCESSING YOUR APPLICATION
=============================================================================

{{- if eq .Values.frontend.service.type "NodePort" }}

The frontend is exposed via NodePort. To access it:

1. Get the Minikube IP:
   minikube ip

2. Access the application at:
   http://<MINIKUBE_IP>:{{ .Values.frontend.service.nodePort }}

   Or use this command to open it directly:
   minikube service {{ include "todo-chatbot.frontend.serviceName" . }} -n {{ .Release.Namespace }}

{{- else if eq .Values.frontend.service.type "LoadBalancer" }}

The frontend is exposed via LoadBalancer. Get the external IP:

   kubectl get svc {{ include "todo-chatbot.frontend.serviceName" . }} -n {{ .Release.Namespace }}

   Once the EXTERNAL-IP is assigned, access at:
   http://<EXTERNAL-IP>:{{ .Values.frontend.service.port }}

{{- else }}

The frontend is using ClusterIP. To access it locally:

   kubectl port-forward svc/{{ include "todo-chatbot.frontend.serviceName" . }} 3000:{{ .Values.frontend.service.port }} -n {{ .Release.Namespace }}

   Then access at: http://localhost:3000

{{- end }}
